# 🏛️ Asterix Tracker

Lesetracker für alle Asterix Comics.

**Live:** https://mycollecto.github.io/asterix-tracker/

## Features
- 📚 **41 Bände** der Hauptreihe
- 🖼️ Echte Cover vom Fandom-Wiki
- ✅ Abhaken mit Konfetti
- 🛒 Amazon Affiliate Links
- 💾 Fortschritt lokal gespeichert
- 📱 PWA – auf Homescreen installierbar

## Reihen

| Reihe | Bände | Status |
|---|---|---|
| Asterix | 41 | aktiv |

## Reihenfolge

Die App folgt der **deutschen Nummerierung** (Egmont Ehapa).

*Hinweis: Die ersten 7 Bände erschienen in Deutschland in anderer Reihenfolge als im französischen Original.*

## Setup
1. GitHub Pages: Settings → Pages → Branch: main
2. Cover: Actions → „Cover-Bilder herunterladen" → Run workflow
